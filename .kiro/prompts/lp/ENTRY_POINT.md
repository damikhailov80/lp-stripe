# Landing Page Generator - Entry Point

## Quick Start

Use this command to create a new landing page:

```
Используй промпт из AI_PROMPT_FOR_LANDING_PAGES.md и создай лендинг для этих товаров: [ссылки на HTML]
```

## Example

```
Используй промпт из AI_PROMPT_FOR_LANDING_PAGES.md и создай лендинг для этих товаров:
- https://example.com/product1.html
- https://example.com/product2.html
- https://example.com/product3.html
```

## What Happens Next

The AI will:
1. Analyze the product HTML pages
2. Suggest a landing page name and ask for confirmation
3. Ask about design preferences
4. Download product images
5. Create all necessary files (page.tsx, data.ts, success/failure pages)
6. Provide a summary with next steps

## Files in This Directory

- **ENTRY_POINT.md** (this file) - Quick start command
- **AI_PROMPT_FOR_LANDING_PAGES.md** - Complete AI instructions
